# data-team

For teams that work with databases, notes and docs. A hosted Supabase server, notes, docs lookup, GitHub and a few small helpers. Database servers that need a connection address are not listed; add your own with your real command.

This is a starting point, not advice. Edit it before you use it. How to use the files, and what to watch for, is in the [main README](../../README.md). Where each entry comes from is in [SOURCES.md](../../SOURCES.md).
